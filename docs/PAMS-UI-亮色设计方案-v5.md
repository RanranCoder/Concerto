# PAMS UI 亮色设计方案 v5

日期：2026-10-13。范围：整个 PAMS 系统，重点为工作台与业务页面，兼顾灵思。本文是设计提案，不表示业务功能已开发。视觉原型：`PAMS-UI-bright-v5.html`，全部数据为演示数据。

## 设计定位

建议采用「明亮的校园协作工作台」：清透的白色工作面、带蓝调的浅色背景、醒目的蓝色操作点，辅以青绿、琥珀和紫色的信息分区。适合指导老师、主任、部长与干事长时间处理活动、排班、台账及材料。

当前项目已有院校蓝 `#0034A2`、浅灰底以及灵思灰阶界面。这次调整保留品牌识别，扩大有业务意义的彩色区域，让用户通过色块快速识别日程类别、工作入口及状态。页面的主要记忆点是本周工作日历：真实的活动、值班、文书节点成为彩色信息块。

方案取舍：不以四张相同的统计卡作为首页主视觉；统计收为一行摘要，把空间留给本周工作。多种颜色主要进入日历、模块入口和状态，表格正文保持清晰的白色工作面。如此既能满足丰富的亮色要求，也有稳定的信息层级。

## 配色体系

六个核心色构成基础色板，文本、边框、品牌锚点与状态另设语义变量。

| 核心色 | 色值 | 角色 | 使用方法 |
| --- | --- | --- | --- |
| 云蓝背景 | `#F4F7FD` | 全站背景 | 大面积低彩度背景，区分白色工作面 |
| 纯白工作面 | `#FFFFFF` | 表格、表单、正文 | 承载高密度阅读与编辑 |
| 明亮钴蓝 | `#315BEF` | 主操作与当前位置 | 主按钮、选中导航、焦点、活动类别 |
| 青绿 | `#148779` | 排班与协作类别 | 日程色块、排班入口、辅助图形 |
| 琥珀 | `#E6A23C` | 材料与文书类别 | 材料入口、文书日程、待处理提醒底色 |
| 鸢尾紫 | `#7656CE` | 灵思与知识类别 | 助手入口、产物、知识库类别 |

建议的面积分配约为 70% 白色与中性色、22% 浅彩色、8% 高彩度强调。这是本项目的视觉控制目标，需随页面密度调整，不是普适配色定律。

### 颜色为什么协调

- 钴蓝、青绿、紫色属于相近的冷色方向，承担系统的稳定基调；琥珀提供少量暖色平衡。
- 大面积背景降低彩度、高亮度，小面积操作色提高彩度，避免多个饱和色同时争夺注意力。
- 文字颜色与背景分开定义：明亮的色块不代表使用同色浅文字。琥珀面配深棕文字，青绿面配深青文字。
- 类别颜色与状态颜色属于不同层级：日历色块表示活动类别，状态标签始终附有“进行中”“待审核”等文字。不得依赖颜色单独表达信息。

### 色阶与语义

| 变量 | 背景 / 色值 | 前景 / 色值 | 场景 |
| --- | --- | --- | --- |
| 品牌锚点 | `#0034A2` | 白色 | Logo、组织识别，保留院校蓝 |
| 主操作 | `#315BEF` | `#FFFFFF` | 新建活动、保存、发送 |
| 蓝色浅面 | `#EAF0FF` | `#2648BD` | 选中导航、活动类别 |
| 青绿浅面 | `#E3F4EE` | `#176B58` | 排班类别、完成状态 |
| 琥珀浅面 | `#FFF1D6` | `#80520B` | 文书类别、待审核 |
| 紫色浅面 | `#F0EBFC` | `#6342AB` | 灵思、知识库、AI 产物 |
| 危险浅面 | `#FDECEC` | `#B52E3C` | 错误、逾期、删除确认 |
| 主文字 | `#23314B` | — | 标题与正文 |
| 次级文字 | `#5E6C84` | — | 日期、说明、辅助信息 |
| 边框 | `#DFE6F1` | — | 容器结构，不单独作为输入框识别依据 |
| 控件边框 | `#8492AC` | — | 输入、选择与未选复选框 |

普通文字以 4.5:1 对比度为验收目标；大字和必要控件识别以 3:1 为目标。最终需对实际组合逐项检测，不以“看起来够深”作为验收。弱分割线可以更淡，但不能承担唯一的交互边界。

品牌蓝悬停为 `#264AD5`，按下为 `#203FB8`。组织主题可替换品牌操作色，但应重新生成浅面、文字色和交互色，检测对比度；成功、警告、危险的语义色保持稳定。默认亮色，深色为后续适配项。

## 字体、尺寸与材质

- 中文优先 HarmonyOS Sans SC，未安装时回退 Microsoft YaHei / PingFang SC / sans-serif。不依赖外部字体网络请求；使用字体文件前确认许可。
- 页面标题 28px/650，区块标题 18px/600，正文及表格 14px/400，标签与辅助文字 12px/500。正文行高 1.6；数值使用等宽数字，正文左对齐、数值列右对齐。
- 间距沿用 4px 基准：8/12/16/24/32。桌面内容边距 28px，区块间距 24px，卡片内边距 20–24px。
- 工作容器 16px 圆角、控件 8px、标签 6px；头像与日期标记可为圆形，表格外壳 12px。形状按角色区分。
- 大多数面板用细边框分层；浮层用 `0 12px 36px rgba(35,49,75,.12)`，普通面板最多用很轻的阴影。
- 表格、输入框、AI 正文使用实色底。局部浅渐变可用于灵思入口或登录插画底，面积控制在小范围。
- 图标沿用项目 Ant Design 图标体系，统一 18–20px 线性风格；用彩色背景承托图标，不把每个图标都单独换色。

## 系统布局

1440px 桌面基准：220px 浅色导航 + 64px 顶栏 + 自适应内容。导航白底，选中项蓝色浅面与蓝色文字；组织标识使用院校蓝。菜单文字保持现有业务术语，以下分组为视觉分组建议，沿用现有权限显隐。

```
┌───────────────┬────────────────────────────────────┐
│ 组织 / PAMS   │ 当前位置              通知 / 个人 │
│               ├────────────────────────────────────┤
│ 日常工作      │ 页面标题、说明             主操作 │
│ 工作台        │                                    │
│ 活动管理      │ 主要工作区                         │
│ 排班考勤      │                                    │
│               │                                    │
│ 组织与资料    │                                    │
│ 台账 / 成员   │                                    │
│ 内容 / 档案   │                                    │
│               │                                    │
│ 灵思 / 知识库 │                                    │
└───────────────┴────────────────────────────────────┘
```

通知和个人操作固定在顶栏；搜索仅在支持搜索的页面出现。侧栏折叠后保留图标与悬停名称。移动端以抽屉导航替代侧栏。不要同时展开多个长子菜单占满导航。

## 重点页面

### 工作台：以本周工作为中心

```
页面标题 + 日期                                      新建活动
┌────────────────────── 工作摘要 ────────────────────────┐
│ 活动总数       进行中       本周排班       我的待办      │
└────────────────────────────────────────────────────────┘
┌──────────────── 本周工作 ───────────────┬── 我的待办 ───┐
│ 周一  周二  周三  周四  周五            │ 逾期 / 截止   │
│ 活动蓝块 / 排班青绿块 / 文书琥珀块     │ 简短操作入口  │
│ 每块：时间、标题、地点或负责人         │               │
└───────────────────────────────────────┴───────────────┘
┌────────────── 近期活动 / 工作列表 ──────┬── 灵思入口 ───┐
│ 名称、进度、负责人、时间、查看         │ 具体任务建议  │
└───────────────────────────────────────┴───────────────┘
```

摘要用一条连续白色区域，数字不必各占一张大卡。主区与右栏比例约 2.2:1。今日列用蓝色日期标记，日程浅彩色块组成主视觉。即将截止或逾期任务优先进入右栏；完成项折叠。

原型日历为工作日视图，正式版本须支持全周，以显示周末活动；窄屏默认“今日”，可切换其他日期。新增“待审核”等聚合必须确认角色范围与接口支持，不能用无权限的数据填充。

### 活动管理：彩色信息入口 + 清晰表格

标题和新建按钮下方放连续状态筛选栏：全部、策划中、待审核、进行中、已结束；当前筛选有浅蓝面和下划线。表格前设关键词、时间、负责人、状态筛选，次要筛选可展开。

表格以活动名称为主信息：标题 14px/600，下一行放活动类型与地点；状态为有字的浅彩标签，任务完成度用细进度条和数值，负责人用头像缩写与姓名。默认 64–72px 行高，紧凑模式 48–56px。最后列保留“查看”，其他操作收进菜单。宽表格优先保证活动名称、状态和操作可见，横向滚动时固定这些列。

详情页的页头显示活动名称、状态、负责人和日期；策划、签到、任务、材料、评分使用现有标签页。任务或日程为左侧主区，右侧显示截止、责任人、审批或材料概况。策划正文使用宽白底文档面，减少装饰。

### 排班考勤：把颜色用于时间与异常

默认周视图，值班浅青绿，活动排班浅蓝；每项同时显示类别文字。冲突和漏签用危险标签，迟到与待核验用琥珀标签。颜色不随成员随机变化。以今天定位、部门筛选和本人排班为首要操作；对冲突提供“查看重叠安排”。

### 台账与成员：稳定的信息密度

左侧阶段筛选，右侧名单表格，选中对象在详情页或抽屉展开。发展阶段使用有序步骤线和文字，当前阶段主蓝，已完成青绿，未开始中性灰。成员详情使用档案式分区：基本信息、发展记录、考察材料，不把个人信息拆成大量彩色卡片。

### 材料、模板、内容与通知

材料和模板采用白色文件列表，琥珀文件图标区强调入口，分类、版本、关联活动明确呈现。上传拖拽区域使用浅蓝底虚线框。内容编辑保持白色文档面，待审琥珀、已发布青绿；通知优先区分未读和紧急程度，未读以蓝点与文字加粗共同体现。

### 灵思：同一品牌下的紫色辅助识别

保留现有对话正文流、任务列表、产物分屏和输入框控制。新任务入口与示例任务加浅紫面，用户消息浅蓝，AI 回答白底。执行过程用简洁状态行，成功青绿、待确认琥珀、失败危险色；产物用浅紫标题带与文件图标，与正文有明确边界。

发送按钮仍为全站主蓝。紫色用于“AI/知识”类别，不替代成功或危险含义。写入前确认在操作卡中说明对象、动作和范围；过程默认摘要，展开查看具体步骤。正式界面沿用现有模型与权限控制，不因视觉改版新增承诺。

### 登录页

左侧以校园活动日历、文件夹、成员协作的简洁平面构图建立主题，蓝、青绿、琥珀组成亮色几何插画；右侧白色登录表单。组织名称明确，输入与按钮对齐，背景图不进入表单。手机上收起大型插画，保留标识与简短说明。

## 交互与自适应

- 主按钮每个操作区保留一个，次操作为描边或文字按钮。按钮默认 36–40px，移动端触达区至少 44px。
- 悬停表格行加浅蓝底，选中行同时有复选框及浅蓝背景。焦点为 2px 蓝色轮廓并带间距。
- 抽屉用于查看与轻编辑；跨步骤任务进入独立页面；确认弹窗列明对象与动作，按钮写“删除活动”“保存排班”等具体动作。
- 空态给明确入口，例如“本周暂无排班，去创建排班”；失败给重试与具体原因；加载骨架保持最终布局，减少内容跳动。
- 动效 140–200ms，仅用于交互反馈；避免日程块自动漂浮、数据不断跳动或全屏渐变循环。尊重减少动态效果设置。
- ≥1280px 为侧栏 + 主区 + 辅助栏；768–1279px 辅助栏移到主区下方，侧栏折叠；<768px 单列与抽屉导航，表格可横向滚动，日历使用日视图。

## 落地顺序与验收

1. 先建立语义 token：在 `pams-web/src/styles/tokens.ts` 定义亮色阶与模块颜色，按现有生成流程输出 CSS，再接入 `theme.ts`。`tokens.css` 是生成文件，不直接改写。
2. 完成 `MainLayout`、页面标题、按钮、状态标签、表格、弹窗的统一外观；保留既有角色权限与组织主题能力。
3. 工作台落地本周工作主区，活动列表及详情形成业务样板；确认日历聚合需要的数据来源，复用现有活动与排班接口，文书截止项若无接口则单独评估。
4. 推广到排班、台账、成员及资料页面，最后统一灵思与登录页。

验收：亮色区域有业务意义；任一页面最多一个主要高饱和视觉焦点；主文字及标签达到对比度目标；状态不依赖颜色；1440/1024/390px 无整页横向溢出；长名称、多行描述、空数据、错误和加载状态可用；键盘能操作筛选与弹窗；组织换主题后仍有可读性。

### 原型核验记录

在本机 Edge 的无头渲染环境中检查了 1440、1024、390px 的工作台、活动管理、灵思和配色页，未发现整页横向溢出。活动状态筛选、名称搜索、详情弹窗、移动日期切换与导航开关运行正常，未出现页面脚本错误。桌面及手机截图已另存于 docs 同名前缀 PNG 文件。

按 sRGB 相对亮度公式计算：主按钮白字 5.42:1、主文字白底 13.02:1、次级文字云蓝底 4.95:1；蓝/青绿/琥珀/紫/危险标签的指定文字与浅面组合分别为 6.71/5.62/6.01/6.21/5.37:1，控件边框对白底为 3.14:1。上述指定普通文字组合达到 4.5:1 目标；这是配色和原型的局部核验，不等于正式系统的完整无障碍认证。
