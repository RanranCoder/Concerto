1. 结构

桌面：容器 max-width 1000px，左 45% 深色表单 / 右 55% 渐变品牌板，最小高 620px。深色表单面板内：品牌标识（顶）→ 表单（垂直居中，宽 ≤330px）→ 版权（底）。窄屏 ≤860：只保留深色表单面板，隐藏渐变板（表单是唯一的任务路径）。

2. 与 v4 设计系统的一处取舍（需你确认）

v4 明确要求「去渐变、去装饰」。参考稿的右侧渐变 + 巨型描边字属于对外的品牌落地页表达，与内页系统不同。本稿把它限定在右侧一个面板内（不进入内页、不进入表单区），作为 v4 §10 允许的「仪式场景」处理。若你希望完全贴 v4，可把右板换成纯色 --brand 或 --brand-soft。

3. 组织选择（核心新增，需后端配合）

现状后端没有免登录的组织列表接口（GET /api/orgs/current 需登录）。落地「登录前选组织」二选一：

方案做法代价
A 公开列表（本稿采用）新增 GET /api/orgs/public（免登录，仅回 id/name/shortName/logoUrl/themeJson），前端下拉选择 + localStorage 记忆需 1 个免登录只读接口（注意脱敏）
B 组织链接进入不改接口，注册后给入口链接 /login?org=<code>，按 code 拉公开品牌仍需按 code 取品牌的公开接口
