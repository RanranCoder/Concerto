# 花名册批量开户流程

用户管理和成员管理的「账号关联」均提供「从花名册导入账号」。操作者必须同时拥有治理能力 `member:import_account`、`user:manage`、`role:assign`。

## 使用方式

1. 选择届别，勾选待开户成员。仅支持有有效学号的在职成员，单批 1–200 人。已有账号、已删除账号保留的用户名不进入候选名单。
2. 根据职位和部门自动预选当前可分配的已发布角色：主任/副主任 → 主任；部长/副部长 → 组织部、文秘部、新媒体中心、青年科技部各自的部长；干事 → 干事。可以逐人修改，或统一应用其他角色。没有匹配的部门、角色未发布或超出授权范围时不自动赋值，提示手动选择。
3. 预览每个人的姓名、用户名、部门、角色及业务权限。当前业务范围为本组织全部，不产生管理员身份。预览有效期 10 分钟。
4. 确认后整批创建账号，初始状态为「待设密」。重复提交同一个预览不会重复创建。
5. 点击「下载开户凭证」，生成每人独立、48 小时有效的一次性设密链接并下载 Excel。管理员将每个人的链接分别交给对应成员。
6. 成员打开链接、设置至少 8 位密码并确认后，账号启用，再使用学号和新密码登录。

重新打开导入面板可查看本人最近 20 个已创建批次并补发凭证。每次重新生成会替换该批次所有尚未使用的旧链接；已激活账号不受影响。当前面板内的「再次下载」使用内存中的同一份链接，不再次生成。响应丢失或下载失败后，可以重新生成，无需重新开户。

## 一致性与权限

- 预览、确认和补发均验证当前治理身份、组织归属及可分配角色；预览绑定操作者和组织，其他管理员不能操作该批次。
- 确认时检查组织授权版本、预览有效期和所选成员/角色的最新资料。发生变化返回 409，必须重新预览。
- 批量开户不复活软删除账号，不通过固定角色码查找全局角色，不使用固定密码，不写管理员委派。
- 创建和凭证发放与组织授权变更使用同一组织锁；开户确认期间锁住所选成员。事务使用 READ COMMITTED，等待锁后重新读取已提交的授权。创建冲突时整批回滚。
- 设密令牌使用 256 位随机数，数据库仅保存 SHA-256 摘要，成功使用后清除摘要。设密前检查期限、账号原始待激活密码标记、当前组织/账号/角色状态。账号常规编辑或删除会使旧链接失效；密码被另行设置的账号不能通过原批次重新发放链接。
- 链接将令牌放在 URL fragment，不进入普通 HTTP 路径或 Referer。发放响应禁止缓存；浏览器不持久化令牌。创建、发放和激活记录写入治理审计，不包含密码或原始令牌。

## 接口与迁移

新增 V38 迁移，建立 `member_account_batch`（请求和授权预览快照）与 `member_account_credential`（待激活账号、凭证摘要和消费状态）。启动后由 Flyway 自动执行；前后端需一起更新。

| 接口 | 用途 |
| --- | --- |
| `GET /api/members/account-batches/sessions` | 开户届别列表 |
| `GET /api/members/unregistered?sessionId=...` | 候选成员 |
| `POST /api/members/account-batches/previews` | 提交届别、成员 ID 和逐人角色 ID，返回预览 |
| `POST /api/members/account-batches/{id}/apply` | 确认已保存的预览，不接受新的角色或成员参数 |
| `GET /api/members/account-batches` | 本人的最近开户结果 |
| `POST /api/members/account-batches/{id}/credentials` | 重新生成尚未激活账号的设密令牌 |
| `POST /api/auth/account-setup` | 无需登录，凭有效令牌设置密码并激活 |

旧 `POST /api/members/import-accounts` 保持 409，防止绕过预览。

## 验证入口

- 后端 `MemberAccountImportServiceTest`：完整预览/创建/发放/设密/登录链路、幂等、整批冲突、跨组织与操作者隔离、授权收回、期限、链接替换、普通编辑/删除使链接失效。
- 后端 `TenantRoleManagementTest`、`UserServiceTest`、`PermissionGuardIntegrationTest`：现有治理、用户管理及业务入口回归。
- 前端 `e2e/member-account-import.spec.ts`：逐人角色指定、预览后才创建、真实 Excel 下载内容、历史结果恢复、过期预览、入口权限与公开设密页面。页面接口使用独立测试数据。

角色下拉浮层在开户抽屉内部渲染，使用真实选项节点供鼠标/触屏选择。候选名单和角色每次刷新一起加载，按最新角色清单预选；历史批次加载独立进行，失败不阻断成员和角色的选择。手动调整在进入预览并返回时保留。
