# 支持范围内 DOCX 视觉核验

已打开并逐页检查原版和修订版的全部两张页面图：文字可读，无裁切、重叠或缺字，页面行数、段距、粗体、活动日期、地点和流程保持一致；预算由2500变为3000。自动像素差异仅位于预算数字区域，其他区域逐像素相同。XML语义对比仅有该文本变化，其他包部件字节完全一致，原文件保留。

渲染器身份须以PDF元数据为准：本机 `Word.Application` COM 实际由 **WPS 文字**响应，不能据此宣称通过 Microsoft Word 验收。标准 `render_docx.py` 因本机没有 LibreOffice 而失败，日志保留；COM导出后的退出阶段曾返回RPC错误，两份PDF均已成功生成并核验。未安装新Office软件。

样本为项目原生POI生成、符合当前白名单的段落DOCX。仓库现有6份实际DOCX和1份常见模板生成的DOCX均被当前包白名单拒绝，未修改或发送给外部模型。详见 `real-document-format-probe.json`。这证明当前拒绝边界，并不表示这些文档已经具备修订能力；复杂格式和Microsoft Word独立渲染仍未验收。
