## 本轮修正的验收缺口

- 通知现已改为 outbox 异步投递，test profile 停止定时任务；验收显式执行 worker，检查收件箱，而非只检查 notification 记录。
- 工具矩阵改用自由结构 documentBody，避免只覆盖旧章节参数。
- 增加真实模型自由结构策划书及旧版本保留测试。
- 浏览器脚本同步版本选择按钮名称、新知识库分页结构、策划书权限和材料分页结构。
- 浏览器验收增加 Agent 策划书全文显示、原稿保留、Word 编辑保存的完整流程。
- 独立浏览器验收使用单独输出目录，避免并行运行其他 Playwright 测试时互相清除追踪文件。
- 修复通知流的会话竞态：已中止/过期连接的迟到 401 不再清除当前会话；活动连接收到 401 时先通过 REST 复核会话，避免流或代理异常造成意外退出。新增覆盖了旧流迟到、真正会话失效、仅流失效但会话有效的测试。

## 建议完善顺序

1. **当前 Word 全文的读取与定向修订（优先）**。现有工具没有专门按策划书版本读取原生文档全文的入口。应按版本和权限返回 documentText、版本 ID、revision，再支持“只修改预算/保留其余内容”。写入继续使用版本检查，不能把生成新稿等同于对原稿的准确修订。
2. **版本对比与局部采用（优先）**。目前选择保留或使用整份新稿。可展示当前业务版本与生成稿的逐段差异，支持局部采用，并标注哪些事实来自活动资料、哪些为模型建议。
3. **活动查询完整性**。QueryActivityOverviewTool 先取最多 200 条，再在内存中过滤关键词、日期、状态。大量活动时可能漏掉匹配记录。应把筛选下推数据库，或明确提供完整分页与截断提示。
4. **长文档与格式保真**。Agent 成果编辑仍有 24000 字段字符限制；编辑回传会先转为纯文本，再包装段落，可能失去表格等格式。宜统一为原生文档修订或结构化文档变更，同时清楚区分全文、检索摘要和预览。超过审查预算的长文当前会显示 UNVERIFIED，后续可分段审查。
5. **SSE 正常断开日志**。浏览器离开页面时 SSE 客户端中断会被记录为 ERROR，并尝试对 text/event-stream 写 JSON 错误响应。应区分正常断开和执行失败，避免误报。
6. **持续验收**。在 CI 中常规运行全量测试；独立 MySQL 工具矩阵、真实模型小样本、进程恢复与浏览器闭环作为显式启用的专项任务。通知必须校验收件箱、文档必须校验实际字节、业务写入必须校验重复确认。
