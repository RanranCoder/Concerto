1b · 深色层级阶梯

逐级提亮约 4–6%，不靠阴影；凹陷控件反向压暗
page 页面底0 级
canvas 卡片 / 表格 / 弹窗1 级
soft 侧边栏 / 表头 / 只读区2 级
soft-strong 选中底 / hover3 级
sunken 输入框 / 搜索框（比卡片更深）凹陷
切到深色看效果：整屏为中性灰（#17181A），不含蓝调 —— 带蓝调的底会把整页染成「蓝色蒙层」。 相邻层级亮度差约 1.08–1.14，与参考站（#17181A → #242628）一致，属于「可感知但不突兀」的深色层级做法。
