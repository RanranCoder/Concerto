## 管理入口

灵思页面顶部的“长期记忆”打开个人管理抽屉。支持新增、编辑、候选确认、删除、有效期、项目范围、搜索、状态筛选和关闭读取。名称和范围在编辑时固定，避免重命名变成新建；修改和删除携带原 revision，冲突时保留草稿、刷新数据并显示错误，不静默覆盖。

关闭记忆后新增、编辑、确认均不可用，查看和删除仍可用。失效记录默认不占用当前列表，可切换全部状态查看。删除前以内联确认说明其不会删除旧聊天记录。所有列表和数量来自同一个响应，不展示虚构使用量。

设计采用 achromatic-ledger，seed `1866309948`，保留现有品牌色与字体。页面的主问题是“灵思正在记住哪些属于我的要求”，主内容为逐条记忆与确认动作，保留组织私有范围、项目标签和到期时间。没有额外 KPI 卡或装饰性图表。默认界面、深色主题在 1440、768、390 宽度检查；统计保持次要，可展开查看。

## 观测

GET `/api/agent/memories/metrics` 仅返回认证身份对应组织与用户的聚合统计：摘要调用、生成失败、校验/存储拒绝、平均耗时、成功写入、缓存命中、并发丢弃、长期记忆读取/命中和选择条数。平均耗时只计算完成的生成调用。失败率包括模型生成失败和生成后的校验/存储失败，并发丢弃单列。

摘要输入/输出 token 直接来自供应商 Usage；供应商未提供时为 null，界面显示“—”，不以零代替缺失。另记录输入正文估算字节，明确不是精确 token 或费用。统计不包含正文、偏好值、对话 ID、成员信息或模型推理。只在进程内保存，按用户与组织隔离，最多 1024 个窗口、每窗口最多 24 小时；服务重启或容量回收可能提前清空。未提供价格换算或前后收益对比。
