# PAMS 前端视觉与交互规范

2026-10-23，根据用户提供的十条规范实施。

1. 容器用灰阶分层，通用边框透明。浅色页面 `#f5f5f3`、内容面 `#fcfcfb`；深色依次采用 `#0b0b0a`、`#151515`、`#1a1a19`、`#20201e`。品牌色与业务状态色沿用组织配置。
2. 输入焦点使用内侧 1px 加外侧 3px 双环阴影，取消输入 outline。错误与警告焦点环跟随语义色；按钮和链接保留键盘焦点提示。
3. 所有应用文字的显式字重通过 `--font-weight-compensation` 计算，浅色减 0、深色减 40。Ant Design 主题的强调字重同步补偿。静态字体实际呈现受字体支持的字重档位影响。
4. 按最新反馈，灵思从固定每字 30ms 改为自适应显示：正常字素间隔 8ms，积压时压缩尚未开始的队列，目标排队窗口不超过 320ms；正文完成时压缩至 100ms 收尾窗口。保留 90ms 的 `blur(6px)` 显现和 `cubic-bezier(.215,.61,.355,1)` 缓动，同一显示帧的相邻字素共用效果。一次输出跨网络分片、句子和 Markdown 段落连续推进。按原始文本位置保留显现进度，Markdown 补齐与推理展开、收起不重播。历史记录直接展示，Markdown 消毒与引用委托保持生效。
   - 阶段衔接：思考结束、工具开始、下一轮思考开始、生成结论或任务终止时，立即补齐上一阶段已收到的文字，不让装饰动画拖延真实流程。首个正文分片在批处理通道中同步结束推理状态；结果生成时过程区标题同步为“正在生成结果”。新思考轮次仍独立显示当前进度。
   - 性能：仅给当前显现窗口（提前 32ms）内的文字创建效果，每个输出最多 12 个模糊动画；后续文本合并为隐藏文本段，已显示文字合并为普通文本节点。分片更新保留 Markdown 元素与仍在运行的动画节点；所有输出共用一个动画帧调度器，收起的推理不运行不可见动画。引用角标整体显现，排队期间不参与键盘导航。稳定的引用编号集合不重复解析 Markdown。
5. 行内图标使用 `vertical-align: -0.125em`。
6. 应用文字默认启用 `font-variant-numeric: tabular-nums`。
7. 灵思过程、专家团队、成果列表和执行明细使用 Grid `0fr → 1fr` 折叠。关闭内容同步设为 inert，退出键盘导航。
8. 正文启用 `text-wrap: pretty`。
9. 动效参数集中在 `src/styles/motion.ts`：位移/拖拽使用 `1200/80` 过阻尼响应，确认使用 `380/18` 欠阻尼响应。当前拖拽选区直接跟随指针；未来增加拖拽落位动画时复用 `--ease-drag`。复制对勾和点赞已使用 `--ease-feedback`，折叠使用 `--ease-drag`。
10. 复制成功显示对勾，2.5 秒后淡出并恢复复制图标；重复复制重新计时，卸载取消计时，失败显示提示。

入口：`src/styles/tokens.ts` 为颜色唯一来源；`tokens.css` 由 `buildTokenCss()` 生成；`refinement.css` 收口公共行为。所有新动效遵循系统“减少动态效果”设置。文档正文、二维码及打印内容保留其内容格式要求。

## 发送后的滚动

发送或重新生成时，把新一轮用户消息滚动到对话区顶部内边距处；短回复也为最后一轮保留一屏高度，让后续过程与回复落在其下方。只在发送时定位，后续分片不会反复置底或打断手动阅读。切换任务清除该定位与占位。容器尺寸变化时更新占位高度，并在发送后下一帧校正多行输入框收缩带来的视口变化。桌面平滑滚动，系统减少动态效果时直接定位。

浏览器回归覆盖桌面与手机、按钮与 Enter 发送、长历史中发送、多行输入、连续发送、更新回复时保留手动阅读位置、切换任务清除定位。

生成中且距离底部超过 24px 时，在输入框上方居中显示 48px 圆形“回到底部”按钮。静止向下箭头搭配 1.4 秒旋转的品牌色弧线，明暗主题沿用页面色板；减少动态效果时弧线静止并直接定位。点击后回到底部并跟随本次后续输出，手动上翻、触摸或拖动滚动条会退出跟随；到达底部、正常完成或停止生成时隐藏。滚动监听和尺寸观察局限在按钮组件内，并按动画帧合并检查，卸载或生成结束时清理。
