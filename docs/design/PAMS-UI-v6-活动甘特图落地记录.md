# 活动任务计划 V6 落地记录

2026-10-26。用户已审查原型并授权落地。

## 页面与流程

活动详情增加“任务计划”首个标签，位于“基本信息”之前，以组织主题色圆角矩形衬底强调。具有 `task:view` 的用户默认进入任务计划；其他用户保留基本信息入口。详情的活动身份、阶段条和其他业务标签继续复用现有页面。

访问 `/activities/:id?tab=gantt`；原 `/activities/:id/gantt` 链接自动转入该标签。基本信息里的任务摘要可进入对应任务详情，任务保存后同步更新摘要与完成数。

- 部门分组与折叠、固定任务列、同步时间轴、依赖箭头、今日与活动日标线、日/周/月/全览尺度、时间定位和前后周浏览。
- 搜索名称/负责人、部门筛选、逾期/前置冲突/未排期筛选、清除条件和无结果恢复。
- 同一任务抽屉展示责任、日期、进度、前后置关系、说明，以及有权访问的活动业务入口。
- 新建任务可暂不填写日期，进入未排期；里程碑选择单个日期，以菱形展示。
- 点击、键盘打开详情；拖动普通时间条先预览改期，取消不写入。
- 任务安排编辑与执行进度更新分别检查权限；归档活动在客户端和服务端均为只读。
- 抽屉包含未保存离开保护，保存失败保留输入；每次编辑独立持有 Form 实例，避免任务之间串值。
- 手机默认显示任务列表，可切换甘特图；图表独立滚动，页面无整体横向溢出。沿用组织颜色、明暗主题与减少动态效果设置。

任务完成比例按完成数 / 总数计算。逾期使用真实当前日期。任务完成不自动改变策划审核、推文发布或活动生命周期。

## 服务端与数据

`TaskService` 增加影响预览、整组保存和版本保护。任务只有一个前置任务；采用“前置完成后的次日开始”的日期规则。仅保存当前任务时保留后续日期和冲突提示；选择顺延时保持后续任务原工期与进度。

| 接口 | 用途 | 权限 |
| --- | --- | --- |
| `POST /api/tasks/plan/preview` | 返回当前提案、后续任务影响与任务图版本凭据 | `task:manage` |
| `POST /api/tasks/plan` | 重新检查预览版本，在同一事务中保存当前任务及所选顺延范围 | `task:manage` |
| `POST /api/tasks/plan/undo` | 按操作回执恢复涉及的任务，版本不匹配时拒绝覆盖 | `task:manage` |
| `PUT /api/tasks/:id/progress` | 更新进度、同步 TODO/DOING/DONE/DELAYED，返回新版本 | `task:progress` 或 `task:manage` |
| `DELETE /api/tasks/:id` | 删除前检查后续依赖，返回可撤销回执 | `task:manage` |

同一活动的任务写入使用活动行锁，任务使用 JPA `@Version` 防止覆盖并发修改。保存前重新核对预览所见任务图，撤销逐项核对操作后的版本。新建、编辑、删除与进度更新均校验归档状态；禁止跨活动前置、循环依赖、带后续依赖的删除及跨组织部门分配。历史失效前置可逐项解除，不要求先修复整个活动才能保存。

软删除恢复查询显式约束活动和组织，撤销不恢复活动或其他业务模块的快照。执行成员的进度撤销继续走进度接口，不能调用计划恢复接口。

新增迁移 `V49__task_plan_revision.sql`：添加任务版本列，并允许开始/结束日期为空。历史日期保留；新写入的日期必须成对填写，里程碑归一为单日。现有旧后端进程需要重新启动，Flyway 才会应用迁移和新增接口；本轮没有停止已有服务或修改当前 MySQL 数据。

## 2026-10-27 负责人选人补充

任务编辑的负责人改为可搜索的成员下拉框。先选择负责部门，再输入姓名的一部分进行筛选，或直接展开列表选择。切换、清空部门时自动清空原负责人；没有选择部门时，负责人选择器禁用。

复用登录即可访问的最小字段接口 `GET /api/users/options?deptId=...`。新增部门参数时，仅返回当前组织、所选部门中启用且未删除的账号，不返回用户名、手机号等资料；不带参数的已有选人流程保持原接口行为。前端同时按部门过滤候选项，并忽略已过期的加载请求，防止快速切换部门时串名单。

列表加载失败可重试。已有任务的原负责人不在当前候选中时，保留原记录并提示，可重新选择或清空；新的选择仅来自当前部门候选。沿用任务现有的姓名字段，不增加数据库迁移。

已通过 TypeScript、Ant Design lint、生产构建、13 项任务计划浏览器用例及 13 项后端用例（任务接口 3、用户服务 10）。新增验证覆盖姓名筛选、部门切换与清空、加载重试、慢请求竞态，以及部门/组织/账号状态过滤。选人截图为 `ui-v6-gantt-implementation/assignee-department-search.png`。

## 2026-10-27 时间视图缩放修复

原来的日、周、月尺度都会按容器宽度拉伸短计划，导致切换后比例相同，主轴也一直使用日期刻度。现在由 `gantt.scale.ts` 统一计算范围与日期坐标：日视图每日期宽 42px、周视图 16px、月视图 5px；空余空间通过延长显示日期填充，只有全览按完整计划与可用宽度缩放。

周视图以周一至周日分栏，月视图按真实自然月长度分栏，主轴、网格、任务条、里程碑、依赖线和今日/活动日标线共用同一坐标。删除原有 60/120/180 天的范围截断，跨多月任务可完整滚动查看。月视图按月翻页；全览忽略此前翻页位置并禁用翻页；全览中的“定位今日”转为日视图。

## 2026-10-27 Ctrl＋滚轮缩放

鼠标位于甘特图区域时，按住 Ctrl 向上滚轮连续放大、向下缩小；缩放尽量保持鼠标下的日期位置与纵向滚动位置。日期主轴、任务条、依赖线和日期标线继续共用统一尺度，刻度随密度自动使用日、周或月。缩放范围为每日 0.5—126px，限制单次大幅滚轮输入，兼容像素、行和页三种滚轮单位。

滚轮缩放后时间尺度选框显示“自定义”；选择日/周/月/全览或点击“适合全部”可恢复预设。普通滚轮继续滚动图表。仅在甘特区域使用非被动事件监听阻止 Ctrl＋滚轮触发浏览器缩放，区域外不拦截；监听随组件卸载移除。拖动任务时不同时触发缩放。页面增加快捷操作说明。
