# 活动管理 V6 落地记录

2026-10-20。按已审查的 V6 原型接入正式 React / Ant Design 页面，代码保存在当前工作区；未部署线上环境。

## 页面与业务衔接

| 页面 | 正式实现 |
| --- | --- |
| 活动管理 | 可点击的全局状态摘要、六阶段筛选、名称/主题/负责人检索、组织单位与类型筛选、服务端日期排序、任务和材料真实数量、分页、手机信息卡。 |
| 基本信息 | 活动资料、执行准备、真实任务甘特图摘要、签到数量和工作入口；推进/回退前确认，遵循后端状态机。结束/归档后基本信息只读。 |
| 材料 | 服务端检索、类型筛选与分页；复用实际文件上传、材料关联、预览与下载接口，关闭未上传表单时保护已填内容。 |
| 策划书 | 白色固定 A4 文档工作区、目录、等比缩放、展开阅读；Word 编辑、模板导入、提交和审核均使用右侧抽屉。 |
| 议程 | 连续的有序环节清单；保留环节顺序、备注、新增/编辑/删除与真实 Word 导出。现有接口没有时间、时长和负责人字段，因此不虚构这些信息。 |
| 座位表 | 默认查看实际布局；保留可视化布局、旧版座位与 Excel 编辑入口，编辑能力按 `seat:edit` 控制。模板与配色管理也改为右侧抽屉。 |
| 评分 | 展示真实评分维度和满分、规则管理、结果与同分名次；保留原有分值校验与记录，录入表单使用抽屉。 |
| 签到 | 应签/已签/未签/签到率使用分组汇总接口，分开查看应签名单与实际签到记录；保留导入、补签、二维码、字段配置、手动签到和 CSV。 |
| 推文 | 连续任务列表；查看完整稿件、创建/编辑、审核、发布及统计更新均保留原流程。稿件阅读改为右侧抽屉，包含正文、摘要、图片和审核意见。 |

活动、策划书与推文保存失败会保留输入内容。活动编辑、策划编辑、推文编辑和材料上传增加未保存内容的关闭确认。抽屉使用系统已有的固定标题、固定操作区和独立滚动布局。

权限继续使用服务端既有权限码。策划编辑/提交依赖 `activity:edit`，审核依赖 `activity:review`；待审核策划停止编辑和导入。只读用户不显示活动编辑、材料上传、评分新增和签到管理入口。原 `/activities/:id/edit` 链接保留，打开活动详情中的编辑抽屉。

## Word 文档

- 已保存字段、活动信息覆盖值和自定义章节顺序生成真实 `.docx`，使用 `docx-preview` 在隔离 iframe 中显示。
- 每页固定 210 × 297 mm。深色主题下纸张仍为白色，正文不受系统主题样式污染。缩放仅变换整页尺寸，不按屏幕宽度重排正文。
- 支持适合宽度、75%、100%、125%、150%，以及目录定位、阅读区展开、显式分页和普通段落溢出分页。
- 本地试阅直接渲染所选 `.docx`，不上传、不修改已保存策划书；“返回当前策划书”恢复保存版本。旧 `.doc` 提示另存为 `.docx`。
- “导入 Word”沿用章节解析模型，打开未保存编辑稿，用户核对并保存后才写入接口。它与完整原文件试阅是两个明确入口。
- 修复独立 `flow` 字段在原导出中的遗漏；输出可识别的章节标题与明确 A4 尺寸，支持导入普通段落样式的编号章节标题。
- 待审核内容不能原地修改；已通过内容再次保存建立新版本。界面只展示接口真实提供的当前版本与审核信息，不生成虚构的历史记录。

兼容边界：浏览器预览支持常见标题、正文、表格、图片和页眉页脚。复杂浮动对象、分栏、跨页合并单元格、单行高于整页的表格及字体替换仍可能与桌面 Word 不同。需要精确印刷版式时应下载后在 Word 中核对。导入编辑提取已识别的策划章节，不等同于无损编辑任意 Word 文件；本地试阅保留原文件的展示路径。

## 接口变更

无数据库结构变更。

- `GET /api/activities` 新增可选 `organizer`、`dateOrder=asc|desc`；关键词同时检索负责人。
- 列表返回 `taskCount`、`completedTaskCount`、`materialCount`。先取当前分页活动 ID，再批量聚合任务/材料，避免逐行请求和分页推算。
- 新增 `GET /api/activities/organizers`，按当前组织返回已有活动的非空组织单位，权限为 `activity:view`。
- 聚合查询继续经过 Hibernate 租户与软删除约束。
