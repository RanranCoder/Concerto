# 策划书工作台落地记录

日期：2026-10-21。

编辑器后续已切换为 SuperDoc；当前文档存储、清理范围与验收结果见 [SuperDoc 接入与验收](PAMS-SuperDoc-接入与验收.md)。下文中的旧编辑器与预览实现保留为此前落地记录。

## 已落地的业务

- 策划书首次创建人作为作者；当前版仅作者与本次勾选的审核人可见，其他具有活动查看权限的同组织用户只能读取历史版本。管理角色不会自动获得当前版访问权。
- 提交时至少勾选一位审核人；候选人限同组织、账号有效且同时拥有活动查看、审核权限的成员，排除作者。服务端重新校验名单，拒绝重复、失效、跨组织和本人审核。
- 每位审核人单独记录通过、退回、意见与时间。全部所选审核人通过才完成审核；任何一人退回即结束本次审核，作者须修订新版本。审核不会自动推进活动阶段。
- 已提交、通过、退回、撤回的版本正文只读。修订保留旧版全文及审核记录，新草稿清空审核名单；审核中可撤回并修订，历史版本明确标为“已撤回”。
- 名称、主题、时间、地点、组织与对象随版本冻结，Word 封面与落款也取版本快照。旧数据在迁移时冻结当前可恢复的信息，无法还原迁移前未保存的元数据变更。
- 保存使用活动行锁和版本修订号，防止并发审批丢失、重复版本及过期窗口覆盖新保存内容。

## 页面与交互

正文直接在原文档区域编辑。点击编辑后出现保存、取消和格式工具栏；正文在内部独立滚动，工具栏留在文档区顶部。取消恢复保存内容；失败保留输入；保存成功刷新原处的 A4 预览。

保留 Word/模板导入、自定义章节、活动基本信息同步和 Word 下载。新增版本切换、可见范围提示、逐人审核进度和审核人多选面板。窄屏编辑使用更小的阅读留白和可横向滑动的格式工具栏，导出仍按 A4。

编辑正文不再使用抽屉或弹窗。审核意见和版本记录放在文档右侧常驻侧栏，模板选择保留辅助面板。

### 右侧审核与版本栏补齐

- “审核意见 / 版本记录”两个页签与原型保持对应。审核意见展示所选版本的审核人、审核意见与时间，可审核时直接在侧栏填写并通过或退回。
- 版本时间线展示版本号、当前版标记、状态、说明、时间和实际作者姓名。点击记录会同步切换中间正文；编辑期间禁用版本切换。
- 选择历史版本后，与已保存的当前版本逐章节比较，以红色展示历史内容、绿色展示当前内容，并统计变化章节。元数据、自定义章节及章节顺序也参与比较，纯格式变化单独提示。
- 仅使用当前用户可见的版本生成对比；当前版不可见时只展示历史记录及权限说明，不读取或展示当前正文。差异正文使用纯文本展示。
- 桌面在文档右侧固定显示，侧栏内容独立滚动；窄屏移至文档下方。

## 权限覆盖

活动详情聚合、策划书单版本读取、版本列表、灵思知识检索及来源链接均使用同一版本访问规则。图片下载与旧 `/uploads/` 直链同步校验；保存前校验引用权限，防止通过猜测文件 ID 把私有附件挂到自己的策划书。敏感文件原有权限要求继续生效。

主要接口：

| 接口 | 用途 |
| --- | --- |
| `GET /api/plans/workspace?activityId=…` | 当前用户可见版本、最新可见文档及操作资格 |
| `GET /api/plans/reviewers` | 同组织可用审核人 |
| `PUT /api/plans/{id}/submit` | 提交 `{ reviewerIds: […] }` |
| `PUT /api/plans/{id}/review` | 保存本人的审核决定 |
| `POST /api/plans/{id}/revision` | 保留原版并创建不带审核人的新草稿 |

数据库迁移：`pams-backend/src/main/resources/db/migration/V40__plan_version_reviewers.sql`。新增作者、并发修订号和逐版本审核记录。无明确审核人的旧待审记录恢复为草稿，须由作者重新选择审核人。

## 验证与预览

- 后端已执行全量回归，并对权限读取、多人并发审核、退回、撤回、版本快照、过期保存、附件引用和定向通知执行专项测试。
- 前端构建通过；策划书侧栏、版本对比、交互、Word 往返与编辑安全专项共 20 项测试通过；Ant Design 组件检查无问题。
- 全量前端测试使用 `NODE_OPTIONS=--no-experimental-webstorage` 避免 Node 26 测试环境的 localStorage 冲突；仍有 3 项原有的全局字号、颜色、圆角约束失败，涉及现有页面样式及 HeaderStaff，未扩大本次修改范围。
- 实际浏览器验证了原地保存、取消编辑、勾选多人和桌面、390px 窄屏布局。
- 既有 `activity-v6.spec.ts` 的模拟接口与编辑断言已同步新流程，并验证脚本语法；本轮浏览器验收通过实际页面操作完成，未批量执行 Playwright 用例。
