# V6 成员、宣传、档案与党务台账落地记录

日期：2026-10-15。根据用户确认的 `PAMS-UI-bright-v6.html` 原型，完成正式 React 页面更新，复用现有 Ant Design 5、主题 token、接口及权限体系。本轮未修改后端或数据库。

## 已落地

- 成员管理：届别选择、全届统计、部门目录、名册与账号关联页签、标准 / 紧凑表格、成员详情与任职信息。详情的“编辑资料”返回名册并打开真实编辑表单，权限受 `member:manage` 控制。原有 Excel 导入 / 导出、模板下载、批量删除、届别管理及换届归档保留；导入报告补充跳过数量。
- 账号关联：仅拥有 `member:import_account` 的用户可见，读取真实未注册成员，明确选择系统角色后调用现有创建账号接口。角色选项受当前用户级别限制，不提供指导老师角色，提交 `roleCodes` 而非依赖成员职务默认映射。
- 内容宣传：推文 / 新闻稿统一模块导航；推文总数及状态统计读取真实接口总数，保留状态 / 类型 / 活动筛选与分页。列表收敛为稿件、状态、作者、日期与操作，发布链接、传播数据和长图仍可在详情查看。
- 稿件审阅：正文 / 长图与审核意见并列，驳回必须填写原因。保存、提审、审核通过、发布链接登记、传播数据回填沿用原接口。新闻稿保持草稿 / 发布流程，补齐可选活动关联，并保留编辑时的关联信息。
- 材料与档案：材料分类目录、按活动筛选、真实分页文件列表、归档详情、文件预览 / 下载与元数据编辑。编辑保留原始文件关联，不假造文件内容或上传结果。模板库改为文件卡片，保留分类、预览、使用、下载、上传和删除。
- 素拓加分、通知公告、群聊管理接入统一档案导航与列表外观，保留原有业务操作。群聊卡片与列表的管理操作统一按 `chat:manage` 显示，手机宽表在自身容器滚动。
- 党务台账：发展台账 / 名册导航、真实阶段人数、个人阶段带、发展时间线及函调 / 登记 / 转移页签。个人详情增加阶段记录入口，已有流转历史时只允许选择下一阶段，正式党员已完成流转时禁用追加入口；后端顺序校验保留。专项记录表格与敏感字段角色控制保留。
- 全局侧栏：将材料、模板、素拓、公告与群聊归入“组织与资料 → 材料与档案”，每个子项仍按原权限显示。党务页面纳入 V6 业务布局，使用 216px 侧栏、26px 页标题与手机抽屉；知识库和协作实验保留独立布局，灵思维持已有 V6 布局。

## 与原型的必要差异

- 成员列表接口没有账号关联标志，不将缺少标志解释为“未关联”。账号页明确只展示接口返回的有学号、未注册成员。
- 本届摘要使用现有成员统计接口；第四项显示真实“职务类别”，不添加无权限时无法读取的账号统计。
- 任职信息来自当前成员档案，不虚构跨届履历。排班、考勤和素拓摘要直接读取成员详情接口。
- 新闻稿接口没有全量状态聚合统计或服务端状态筛选，本次保留真实分页与关键词查询，不将当前页统计冒充全量。
- 材料按现有分页接口筛选类型和活动，不用原型示例计数填充目录。上传人无可用姓名时展示记录 ID，文件预览仍使用原文件组件。
- 已存的党务阶段才显示“已记录”，没有历史的阶段不自动标为完成。名册与个人发展档案分别维护，不根据同名人员自动写入关联。

- `pams-web/src/components/records/`：模块导航、目录、统计、文件标记、稿件工作面与成员账号页。
- `pams-web/src/styles/records-v6.css`：限定到新页面的布局和响应式规则；字体、圆角和明暗配色使用现有语义 token。
- `pams-web/src/pages/member/`、`content/`、`archive/`、`party/`：各业务页面。
- `pams-web/src/layouts/MainLayout.tsx`：归并档案导航，启用党务 V6 布局。
- `pams-web/src/components/glass/StatusTag.tsx`：补齐稿件五种中文状态与稳定色调。
