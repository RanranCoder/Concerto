# V6 成员、宣传、档案与党务台账原型

2026-10-15。本次仅扩展 `PAMS-UI-bright-v6.html` 原型及其 CSS / JS，不修改正式前后端业务代码。需用户审查确认后再实施。

## 设计依据与共用规范

已对照 README、路由、成员 / 推文 / 新闻稿 / 材料 / 模板 / 党务 API，以及现有详情页、公告、素拓和群聊页面梳理范围。延续 V6 院校蓝 `#1668DC`、内容白 `#FFFFFF`、页面灰 `#F4F6F9`、正文灰 `#263243`、材料橙 `#C17B20`；深色直接复用 V6 语义变量。中文沿用微软雅黑 / 苹方字体栈，标题 26px、正文 13–14px、辅助信息 11–12px。页内统一左对齐，20px 工作区间距。

不把四个模块重复做成同一种统计卡片页面：成员用部门目录与名册，宣传用稿件列表与审阅文档面，档案用材料目录及文件预览，党务用发展阶段与个人时间线。统计仅承担可核对的业务摘要。列表筛选、主操作、面板和弹窗复用 V6 尺寸与颜色语义。

## 评审入口

打开 `PAMS-UI-bright-v6.html`，从左侧“组织与资料”进入四个新页面。也可在文件 URL 后增加：

- `?view=members#light`：成员管理。
- `?view=publicity#light`：内容宣传。
- `?view=archives#light`：材料与档案。
- `?view=party#light`：党务台账。

`#dark` 可直接预览深色。原工作台、活动、排班与灵思入口保留。

## 成员管理

届别为第一层范围，部门目录为第二层，状态和关键词为列表过滤。名册显示姓名 / 学号、部门 / 职务、班级、状态和账号关联；标准与紧凑密度可切换。详情集中基本资料、工作履历、排班 / 考勤 / 素拓摘要及相关入口。

账号关联是独立页签，未关联成员可模拟创建账号并单独选择系统角色。职务不自动映射权限。可演示新增 / 编辑、创建届别、导入检查结果、导出当前筛选。当前演示姓名与业务样例相互关联，不使用真实个人数据。

## 内容宣传

推文与新闻稿分开维护。推文严格保留现有五种状态：草稿、待审、待发布、已发布、被驳回；新闻稿保留草稿与已发布，不虚构共用审核流程。

稿件详情以正文为主，右侧为审核意见或流转摘要。待审稿支持核对项、通过、驳回；驳回必须说明原因。草稿可保存并提审，审核通过后登记公众号链接，发布后手动维护阅读与点赞数。新闻稿独立编辑与发布。关联活动及材料入口可跳转。

## 材料与档案

保留材料库、模板库、素拓加分、通知公告、群聊管理五类入口。材料库使用“类型目录 + 活动筛选 + 文件列表”，显示文件格式、业务类型、关联活动、部门、上传人、日期与标签；预览页将文件工作面与归档元数据并列。模板以可辨认的文件格式与用途展示，避免与已归档材料混淆。

可演示上传元数据、新增模板、素拓 / 公告 / 群聊记录。原型不载入真实文件；文件与模板预览均明确标为示例，下载只生成带原型说明的文本，不伪装为正式业务文件。

## 党务台账

发展台账与名册管理分开。台账顶部五个阶段直接过滤人员列表，阶段只表达发展身份，不把所有阶段染成异常或紧急颜色。个人详情使用阶段带与发展时间线，函调、登记、转移为各自记录页签，可独立追加。阶段流转模拟追加历史并更新当前身份，未引入自动审批或自动政治审查结论。

名册保留推优、通过、汇总、发展对象、转移五类及期次字段。个人台账可跳转关联成员，组织成员名册与党员发展档案仍然分别维护。

## 原型边界与落地待对齐项

- 全部数据和变更只保存在页面内存，刷新后恢复，不发业务 API 请求。
- 导入结果展示为明确标注的示例，未解析 Excel；账号创建、文件上传、发布均为本地演示。
- 个人时间线与工作摘要使用演示数据；后续应按真实接口能提供的记录实现，不能将示例视为新增后端能力已经存在。
- 正式落地需复用现有权限码、角色、组织隔离、敏感字段范围与文件访问校验。顶栏现有排班演示角色只属于排班模块，不作为新增页面的权限验证器。
- 本轮覆盖关键列表、详情、表单与状态流转；届别归档、批量移除、全部分类管理、真实文件渲染和完整账号策略沿用现有能力，正式实施前补齐对应细节。

## 核验

验证脚本：`ui-v6-records-preview/verify.cjs`，使用本地 Chrome 无头渲染。覆盖四个模块的明暗主题、1440 / 1024 / 390px 页面宽度、无结果与重置、成员新建与账号关联、推文通过 / 驳回 / 发布、档案五类入口、党务阶段流转 / 函调 / 登记 / 转移 / 名册、导入结果弹窗以及原有活动 / 排班 / 灵思导航。截图位于同目录。

宽表格在自身容器滚动，移动端目录改为横向筛选，正文与侧栏改为纵向排列。保留可见键盘焦点、原生表单标签、弹窗 Escape 关闭与减少动态效果支持。
