# PAMS UI v6 落地记录

> 2026-10-15 追加：用户确认新版原型后，成员、宣传、档案与党务页面已进一步重构；党务不再保留旧尺寸。最新范围与验证详见 [组织宣传档案与党务台账落地记录](PAMS-UI-v6-组织宣传档案与党务台账落地记录.md)。下文为 2026-10-14 阶段记录。

日期：2026-10-14。正式前端已接入 v6 明暗主题，主色为 `rgb(22, 104, 220)` / `#1668DC`。沿用现有 React、Ant Design 5、接口和角色权限。

## 已实施

- `styles/tokens.ts`：统一亮色与炭灰深色主题，分离品牌填充、文字、焦点、浮层和活动/排班/材料类别色。`tokens.css` 由生成函数重新输出。
- `styles/theme.ts`：主题颜色接入 Ant Design；业务页面使用独立的控件与表格尺寸配置，保护原尺寸页面。
- `layouts/MainLayout.tsx`：业务页采用 216px 侧栏、56px 顶栏、面包屑和手机抽屉导航。侧栏按原型采用 PAMS 书本标识、独立组织信息、日常工作/组织与资料/智能协作分组与底部真实账号信息，额外保留系统管理分组及全部有权限的业务入口。菜单独立滚动，选中项使用新主色与浅底，明暗主题同步适配；子菜单随当前路由展开。
- `pages/Dashboard.tsx`：工作台按真实日期聚合活动、排班与任务截止，支持工作日/全周和手机日期切换。读取活动分页，避免遗漏第二页之后的周末活动；不添加原型中的虚构时间、进度或人数。
- `pages/activity/ActivityList.tsx`：连续组织活动摘要、状态筛选、搜索、标准/紧凑密度与双行名称。筛选、分页和创建/编辑/推进/删除仍沿用现有流程；工作台新增入口打开真正的新建表单。
- `pages/activity/ActivityDetail.tsx`：显示实际六阶段状态机、任务与文件概况、负责人侧栏和材料标签，保留原策划书、议程、座位表、评分、签到与推文流程。
- `styles/business-v6.css`：公共业务标题、卡片、表格与控件统一，所有尺寸样式限定于业务区域；其余列表、排班、成员、资料及管理页通过公共组件适配。
- 登录页表单接入明暗工作面，保留组织选择、现有品牌与登录行为；旧默认蓝色在前端读取时迁移至新主色，其他组织自定义色保留，不修改数据库记录。
- 全站直接使用主色作为文字的场景改用可读的品牌文字变量，逾期文字使用危险色。主题按钮补齐可访问名称。

## 本次明确保留的布局

智能协作相关 `/agent`、`/knowledge`、`/admin/benchmark` 与党务台账 `/party/*` 不应用业务几何配置，仍使用原侧栏宽度、顶栏、控件、标题、卡片和表格尺寸。按用户追加要求，这些页面的全局侧栏也应用原型品牌与分组结构，内容区布局保持原样。

灵思 CSS 与党务详情只调整颜色声明；对话栏、输入区、产物分屏、阶段记录等组件结构保持原样。没有修改智能协作功能或党务台账业务逻辑。

在同一 1440×1000 浏览器中，对比本次修改前后两页的内容区、对话栏、任务栏、输入区、标题、卡片及表格位置和宽高，差异为零。保护目录的 TSX 与基线比较，除预期颜色替换外无结构变化。记录见 `ui-v6-implementation/protected-layout-check.json`。
