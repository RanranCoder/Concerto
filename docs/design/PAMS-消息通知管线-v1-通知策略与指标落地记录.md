# 消息通知管线 v1：通知策略与指标落地记录

日期：2026-10-29

本批对应收尾计划中的第二批：组织通知策略、每日资讯摘要与运行指标。新增 V56，沿用个人收件箱、MySQL Outbox、SSE。当前为本地验证，未部署生产。

## 组织策略

默认关闭免打扰和每日资讯摘要。组织可配置免打扰起止时间、每日摘要时间，统一使用 Asia/Shanghai，时间精度为分钟。免打扰支持跨午夜，开始时间包含、结束时间不包含；起止相同的配置拒绝保存。

`GET /api/notifications/operations/policy` 需要当前组织审计资格，`PUT` 另外需要当前 `org:manage` 资格。写入采用版本号与行锁校验，陈旧版本返回冲突；每次成功保存保留操作人、版本、具体配置及时间审计。客户端不能指定摘要启用边界，开启摘要时由服务端记录。

运维页面提供配置与刷新入口，只有具备组织配置资格的账号可编辑。切换账号会隐藏旧身份数据，旧请求响应不覆盖新身份配置。

## 免打扰与即时提示

策略控制即时提示，个人收件箱、未读数、SSE 对账和业务待办继续实时更新。安全告知、治理身份、任务办理、审核与排班通知保留即时性，并沿用各类型原有的个人偏好约束；策略不将它们转为摘要。

本批可转换的资讯类型为：新媒体上传、推文发布、素拓/党务经办摘要、导入结果和维护告警。普通公告沿用静默入箱，开启每日摘要时也可纳入；重要或要求确认的公告不纳入摘要。

免打扰期间抑制资讯即时提示，消息创建时处于免打扰时段的资讯在时段结束后也不集中补弹。消费者将按策略静默入箱的状态保存到个人收件箱；之后关闭策略也不把这些已静默记录重新变成即时提示。

开启每日摘要后，资讯原消息改为静默记录，每日用一条个人摘要提示；不开启摘要时沿用原有即时策略。个人关闭某类通知后，该类消息不通过组织摘要重新提示。

## 每日个人资讯摘要

调度默认每 60 秒扫描启用策略的有效组织，按账号分页、逐人事务处理。到达摘要时间后，若仍处于免打扰时段则继续等待；当天可发送时汇总一次。不是向全组织复制相同正文，每位接收人只汇总自己的收件箱。

汇总范围是启用策略后、前一自然日及当日内、上次游标后新增、未读且未归档的可见资讯。使用自然日下界，避免每天扫描相差几秒或延迟入箱导致滚动 24 小时窗口漏掉边界消息。已读、个人关闭提醒的类别、不可见资源和办理型消息均排除。正文只包含日期、类型与数量，原消息及其已读状态不变。

`notification_daily_digest` 按组织、账号、自然日唯一，同时保存扫描游标；无可汇总资讯也记录本日扫描，不产生空通知，后续新增资讯留待下一日。关闭再开启策略不重复发送当天已完成的摘要，历史积压不集中补跑。

摘要消息、来源引用、Outbox 和本日扫描记录同事务提交，回滚可重跑。策略行锁和本日唯一键避免并发重复。读取摘要时重新校验所有来源权限，任一来源丢失或失去资格则隐藏该摘要正文，避免借数量暴露已撤权领域的信息。

## 指标与口径

新增 `GET /api/notifications/operations/metrics`，复用实时组织审计资格校验，只返回本组织计数与时间，不暴露消息正文或收件人资料。

| 指标 | 当前口径 |
| --- | --- |
| 待处理、最老等待、失败、过期租约 | Outbox 与在线唤醒按待处理记录；提醒只计算已到触发时间的待处理计划，未来安排不作为积压 |
| 延迟均值与 P95 | 最近最多 1000 条有完成时间的样本；Outbox/唤醒从入队至服务端处理完成，提醒从计划触发至 SENT |
| 观测重试领取次数 | 本批仪表化后，消费者实际领取第二次及后续尝试时在同一事务累计；不随队列记录重新入队或唤醒记录复用而清零 |
| 保留记录重试信息 | API 另外根据当前尝试次数和手动重新入队审计重建，用于诊断；提醒尝试字段记录的是失败次数，页面明确显示为“记录失败” |
| 事实合并命中 | 同事务相同消息事实被复用，包括受众展开时合并，不宣称是跨事务业务去重率 |
| 个人收件箱重复命中 | 消费时已经存在同一组织、消息、用户的收件箱记录，按实际查询观测累计 |
| 无接收人 / 全部受众跳过 | 已完成消费的事实中，冻结受众为空 / 冻结受众全部失去当前资格 |
| 静默入箱、每日摘要数量 | 当前持久化的静默个人记录数，以及已生成摘要消息对应的自然日扫描记录数（历史累计） |
| SSE 连接 | 本实例注册的本组织连接数，非全局在线人数 |

历史缺少完成时间的数据不伪造延迟样本。在线唤醒完成只表示服务端排队或离线跳过，不表示浏览器已展示、用户已阅读。指标反映可观测的各阶段，不作为阅读回执。

消费者领取同时校验 `next_attempt_at`，避免元数据扫描后状态变化造成提前重试。唤醒对账记录复用时重置本轮计时与尝试状态，独立观测计数保留累计值。
