# 全站表单工作面重设计

## 设计取舍

此次调整了 63 处表单和相关操作工作面：11 处页内工作区、28 处侧边抽屉、24 处紧凑对话框。文件预览、只读详情等保留原有用途。

| 承载方式 | 适用场景 | 本次使用位置 |
| --- | --- | --- |
| 页内工作区 | 长篇写作、多组档案资料、需要持续阅读的审核 | 推文撰写与审阅、活动内推文撰写与审核、新闻稿、策划书字段编辑、党务成员资料、函调、登记、转移、制度文档 |
| 侧边抽屉 | 需要保留当前列表或业务上下文的录入、编辑、配置 | 活动、任务、议程、座位、签到补录、评分记录、成员、届别、用户、管理员委派、材料、模板、素拓加分、活动加分、群聊、分类、公告、党务名册与导入、排班与生成、考勤修正、签到字段配置、灵思信息补全 |
| 紧凑对话框 | 简短录入、明确结果的确认 | 修改密码、阶段流转、发布链接、阅读数据、评分规则、分组重命名、角色信息与授权确认、课程时段、排班发布和取消等 |
| 行内编辑 | 单一字段、修改后需要立刻看到结果 | 群聊分类重命名，替换浏览器原生 prompt |

页内工作区直接替换当前页面或标签页的业务内容，继续使用现有路由与页面状态；提供明确的返回入口和吸附底部的操作栏。抽屉和短对话框继续使用 Ant Design 的焦点管理与键盘行为。

## 表单布局

- 沿用现有字体及主题变量：主色 `#1668DC`、文字 `#263243`、次要文字 `#5B6777`、内容面 `#FFFFFF`、背景 `#F4F6F9`、边界 `#DFE5ED`；深色模式使用对应变量。
- 按业务含义组织字段，例如「成员资料 / 组织与任职 / 补充说明」「稿件信息 / 摘要与底稿 / 排版与封面」。标题和说明用于解释实际填写任务。
- 桌面分组采用两列，正文、地址和上传区域占整行；手机统一单列。旧的固定控件宽度在分组表单内统一拉齐。
- 抽屉和对话框的内容独立滚动，操作按钮留在底部。抽屉宽度不超过视口，适配手机安全区。
- 输入控件统一高度与间距；沿用原有必填规则、初始化数据、权限判断、日期转换和保存接口。
- 表单浮层默认不响应遮罩点击，提供关闭、取消和 Escape 操作，降低填写中误触背景导致关闭的概率。
- 灵思补全表单保留常驻渲染和预填逻辑，避免再次出现已有值未显示的问题。

## 实现入口

- `pams-web/src/components/form/FormSurface.tsx`：显式选择工作面及统一页头、操作栏。
- `pams-web/src/styles/forms.css`：表单布局、尺寸、明暗主题和手机适配。
- `pams-web/e2e/form-surfaces.spec.ts`：新工作面、保存请求、表单重开、行内重命名和手机抽屉检查。
- `docs/design/ui-form-redesign/`：实际运行截图，覆盖浅色桌面和深色手机。

浏览器回归使用隔离的接口数据，检查前端请求与交互；不替代真实后端集成验收。

验证结果：生产构建通过；127 项单元测试通过；19 项浏览器回归通过，涵盖上述新表单测试及现有档案、排班、权限管理流程。实际截图已复核。
