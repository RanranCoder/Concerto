更新日期：2026-10-18。依据 `品牌设计/Concerto_Logo方案与使用规范_V1.7.docx` 落地，替代 2026-10-14 的 C 形协作线方案。

## 产品标识

图形采用两个错落的十六分音符，由两道共同符杠连接。彩色版固定使用品牌蓝 `#1668DC` 与青柠色 `#C7F36B`；浅底字标为深墨色 `#17243A`，深底主体与字标为白色 `#FFFFFF`，青柠音符保留。产品标识不随组织主题换色。

完整字标为“Concerto · 协奏”，描述为“高校学生组织智能工作台”。桌面登录、注册等公开入口显示完整组合；600px 以下隐藏描述。主页侧栏与手机导航使用与登录页一致的蓝底横版组合，按侧栏宽度调整字号并保留描述语。两处蓝底标识统一使用 12px 圆角。

登录页固定使用蓝底横版组合：品牌蓝背景、白色主体与字标、青柠音符；明暗主题下均保持该版本。注册及其他入口继续按界面主题选用浅底或深底标识。

`src/components/BrandIdentity.tsx` 是登录、注册、账号激活、桌面侧栏和手机抽屉的共用入口。组件随应用明暗主题或入口指定版本选择 SVG，字标使用项目字体。组织名称与上传的组织 Logo 继续在组织区域显示，组织主题色继续用于业务操作；灵思保留独立的助手身份。

## 资源与生成

前端 `public/brand/` 提供四种透明底 SVG：

| 文件 | 用途 |
| --- | --- |
| concerto-symbol.svg | 浅色界面，蓝色主体与青柠音符 |
| concerto-symbol-dark.svg | 深色界面，白色主体与青柠音符 |
| concerto-symbol-mono.svg | 单色深墨色版本 |
| concerto-symbol-white.svg | 纯白反白版本 |

SVG 固有尺寸为 1254 × 1254，方形画布内已包含至少可见图形高度 H/4 的净空。页面不得裁去透明留白，也不应拉伸、加描边或改变两道符杠的位置。常规界面按 64px、紧凑界面按 48px 展示，不在图形外添加固定色块或外框。

`public/favicon.svg` 为浏览器小尺寸光学校正版，扩大符杠间隙，并随浏览器系统配色切换蓝色或白色主体。`public/favicon.png` 提供 32px 彩色兼容版本；`public/apple-touch-icon.png` 提供 180px 深墨底彩色图标。

资源统一由 `scripts/make-brand.mjs` 生成。设置 `BRAND_NODE_MODULES` 为包含 sharp 的 node_modules 目录后，执行 `node scripts/make-brand.mjs`。生成工具仅供维护，应用运行与构建不新增依赖。

规范将原图定位为位图视觉方案，尚未几何定稿。本次 SVG 是依据选定轮廓建立的工程矢量稿，采用规范色值；字标沿用项目字体。后续设计师确认曲线与字体母版后，可替换对应资源及字标样式。16px 场景使用独立校正版，不宣称常规 SVG 的正式最小使用尺寸已定稿。
