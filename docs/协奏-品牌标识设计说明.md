# 协奏 Concerto 品牌标识

日期：2026-10-14。基于当前 design 分支及已审查的 V6 工作区设计。

## 产品定位

《PAMS-通用化与多Agent协作改造策划》将产品从单一党建管理扩展为高校学生组织智能工作台，支持不同组织、领域包及组织主题。《PRD-v5-开发规划》强调业务闭环。V6 采用克制的蓝色操作色、实色工作面与清晰层级。

现有登录页和标签页已使用“协奏”，此次统一沿用该名称，消除登录后的 PAMS / 党务管理系统旧字标。

## 标识构成

- 中文主名：协奏。
- 英文名：Concerto。
- 产品说明：学生组织智能工作台。
- 图形：外侧 C 形弧线取自 Concerto，三条工作线汇至共同节点，表达成员与智能助手协作完成工作。
- 字形：沿用项目字体；中文加粗突出识别，英文和定位说明降低层级。
- 颜色：默认项目蓝，跟随组织主题；明暗主题中均以实色底和高对比图形呈现。

产品标识与组织标识分开：左上角始终显示协奏，组织名称在侧栏组织区、页头和登录组织选择区展示；组织上传的 Logo 保留在登录组织选择区。灵思继续作为产品内的智能助手名称。

## 实现与检查

`BrandIdentity.tsx` 为共用标识，登录页、桌面侧栏和手机抽屉复用。无新增依赖、后端接口或数据库改动。标签页默认标题及未知路由标题同步为通用工作台文案。

已通过前端构建、23 项相关单测、5 项既有 UI 浏览器回归。另检查登录页明暗主题、390px 手机布局、组织主题切换；无横向溢出或页面脚本错误。截图位于 `ui-v6-brand/` 和 `ui-v6-implementation/`。
