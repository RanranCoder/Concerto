## 概念（§2 选定）

一句话：**一只猫拍出的红色毛线球，滚过一周的事务，把它们收得整整齐齐，滚回猫怀里系成蝴蝶结。**
每一拍都是上一拍的碰撞引发的——线球撞到课表，课表才被卷整齐；线缠住卡片，卡片才叠起来；线打结，结才成印章。

- 钩子帧：奶油色桌面，猫从画面右下探头，一爪拍出红色毛线球
- 衔接：**毛线球 + 那根红线永远在画面上**——它撞出每一拍；相机是一个连续桌面世界上的跟踪运镜，边界处没有场景切换
- 排除：无整页切换、无 PPT 式并列、无镜头快切（片尾定格除外）、无粒子/彩带
- 美术（本轮点名，非默认）：**cream-cute**（自制，riso 变体）——奶油底 `#FAF3E8`、暖棕墨 `#4A3428`、品牌红 `#DE2910`、樱粉 `#FF8FAB`；中文站酷快乐体（OFL），拉丁 Archivo 800 / Instrument Sans / Geist Mono

## 世界与运镜

一个连续的奶油桌面世界（约 4200×2600 世界坐标），一套 `OM.camera` 跟踪运镜：
开局近景猫 → 跟线球向左到课表 → 下到花名册 → 右移到签到 → 右移到策划书 → whip 甩回猫 → 拉开定格。
手持两正弦慢浮（hold 段归零），每次着陆 `OM.shake`，远景 `OM.lattice` 提供视差。
UI 在本片里是**桌面上的纸卡物件**（真实文案、cream-cute 风格），不是像素级界面复刻——概念轮定下的美术方向。

## 声音（§7）

一套材料一个房间（sfx_palette：air/wood/glass/sub/bubble + 同一混响），事件少于拍数：
paw press（wood thud）、ball pop（bubble）、roll（air/sub 微底）、格子 snap（wood tick ×3 非 6）、
stamp（sub thud + wood）、ribbon（air whoosh）、回程球（air）、bow pop（bubble）、品牌落定（glass 点缀）。
音乐：CC0 playful 曲目垫底（来源与许可记在 score 旁），混不进就合成轻音乐床。
